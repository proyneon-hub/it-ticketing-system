# IT Ticketing System

A production-style service desk application with role-based access, ticket lifecycle management, assignment workflows, SLA visibility, activity history, filtering, pagination, and role-scoped CSV exports.

The project includes a TypeScript Playwright framework with Page Objects, typed fixtures, reusable test data, deterministic mocked regression coverage, cross-browser execution, Axe accessibility checks, and GitHub Actions reporting. A separate safety-gated live smoke suite is available for configured non-production environments.

## Resume Bullets

- Built a full-stack IT service desk application supporting admin, technician, and requester workflows, role-based permissions, ticket assignment, SLA tracking, activity history, and CSV exports.

- Developed a TypeScript Playwright framework using Page Objects, typed fixtures, reusable test data, 19 deterministic mocked functional scenarios across Chromium, Firefox, and WebKit, plus a separate Chromium screenshot workflow.

- Integrated API, UI, accessibility, and operational smoke checks into GitHub Actions with HTML reports, screenshots, videos, and traces retained for failure diagnosis.
