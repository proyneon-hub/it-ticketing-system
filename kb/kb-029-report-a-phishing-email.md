# Report a suspicious or phishing email

Phishing emails try to steal passwords or install malware. Report anything that looks wrong, even if you are not sure.

## Signs of phishing

- An unexpected request for your password, a code, payment details or a gift card.
- A message that creates urgency: a deadline, a threat, or an account about to close.
- A sender address that is slightly different from the real one, or a link whose address does not match the company it names.
- A password reset or a "your account has been used" message you did not ask for.

## What to do

1. Do not click any link, open any attachment or reply.
2. Report it with the **Report phishing** button in Outlook. If there is no button, forward it as an attachment to the security mailbox listed on the intranet.
3. Delete it once reported.

## If you already clicked or entered your password

Raise a ticket straight away and say so. Do not wait. See KB-030 for what happens next.

## Note for the service desk

Route every phishing report to the Security Team at high priority. Do not try to resolve it, and do not ask the user to forward the message to you. A ticket that asks for a "password reset" but describes an unexpected message is a phishing report, not an access request.
