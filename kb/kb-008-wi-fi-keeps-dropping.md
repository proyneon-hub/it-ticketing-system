# Wi-Fi keeps dropping or will not connect

The laptop loses Wi-Fi every few minutes, or shows the network but cannot join it.

## Steps

1. Turn Wi-Fi off and on again using the laptop's own Wi-Fi switch or the network menu.
2. Restart the laptop. This clears most short-lived faults.
3. Forget the network and join it again: on Windows choose Settings, Network and internet, Wi-Fi, Manage known networks, then Forget, and reconnect with your credentials. On a Mac, remove the network in Wi-Fi settings and join it again.
4. Move closer to the access point. Thick walls and lifts weaken the signal.
5. Try another Wi-Fi network, such as a phone hotspot. If that works, the problem is with the first network and not the laptop.
6. Check for a pending system update and install it.

## When to raise a ticket

If several colleagues in the same area lose Wi-Fi at the same time, raise one ticket saying where they sit and when it started. That points to an access point and not to your laptop. If only the VPN drops, see KB-006. Visitors need KB-009.
