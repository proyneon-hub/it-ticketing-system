# Request new software

You can install approved software yourself, and ask for anything else.

## Approved software

1. Open the company software portal from the Start menu or the Applications folder.
2. Search for the program. If it is listed, choose **Install**. No approval is needed.
3. When it finishes, open it once to check it starts.

## Software that is not in the portal

Raise a ticket that includes:

1. The name and version of the software, and a link to the vendor's page.
2. What you need it for, in one or two sentences.
3. Whether it needs a paid licence, and which cost centre would pay.
4. Your manager's name, because new software needs their approval.

The security team checks each new program before it is added. This usually takes several working days. Do not install software from the internet in the meantime: unapproved installers are a common way for malware to get in.

If an approved program's licence has run out, see KB-020.
