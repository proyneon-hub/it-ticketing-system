# An application freezes or keeps crashing

A program stops responding, closes by itself, or shows an error on start-up.

## Steps

1. Wait a minute. A program working on a large file can look frozen when it is not.
2. Save what you can in other programs, then force the frozen one to close. On Windows press Ctrl, Shift and Esc, choose the program and select **End task**. On a Mac press Command, Option and Esc.
3. Open the program again. If it offers to recover your work, accept.
4. Restart the laptop. Programs often fail after the laptop has run for many days without a restart.
5. Free some disk space if the drive is nearly full, and close other large programs.
6. Install pending updates for the program and for the operating system, from the company software portal.

## What to put in the ticket

If it crashes repeatedly, note the program and version, what you were doing, the exact error text, and the time of the last crash. A technician can read the logs from that time. If it started after an update or a new install, say so.
