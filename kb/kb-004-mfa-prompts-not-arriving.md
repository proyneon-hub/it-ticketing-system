# MFA prompts are not arriving on my phone

The sign-in page waits for an approval that never shows up on the phone.

## Steps

1. Check the phone has a data or Wi-Fi connection. Prompts cannot arrive in airplane mode.
2. Open the authenticator app directly. A pending request often shows inside the app even when the notification does not appear.
3. Check notifications are allowed for the authenticator app in the phone's settings, and that Do Not Disturb or a focus mode is not blocking them.
4. Check the phone's date and time are set to automatic. A clock that is a few minutes wrong makes one-time codes fail.
5. Close the authenticator app fully and open it again, then start a new sign-in on the laptop.
6. If the app offers a six-digit code, choose **Use a verification code instead** on the sign-in page and type it in.

## If it still fails

Raise a ticket and say which phone and app you use. If you have changed phones recently, see KB-003.
