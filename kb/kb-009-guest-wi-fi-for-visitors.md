# Guest Wi-Fi for visitors

Visitors use the guest network, which is separate from the staff network and cannot reach internal systems.

## Steps for a visitor

1. Join the network named **Guest**.
2. Open any web page. A sign-in page appears.
3. Enter the access code your host gives you, and accept the terms.

## Steps for the host

1. Ask the service desk for a guest access code before the visit, and say how many visitors and for how long.
2. Give the code to your visitors. Codes expire at the end of the day.

## Things that do not work

- Visitors cannot print, open internal websites or reach shared drives from the guest network.
- Staff laptops must not use the guest network. If your own laptop cannot join the staff network, see KB-008.
