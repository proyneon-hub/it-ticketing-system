# Keyboard, mouse or trackpad stopped working

An external keyboard or mouse does not respond, or some keys or the trackpad on the laptop itself have stopped working.

## External keyboard or mouse

1. Check the batteries, or charge it if it is rechargeable, and check the on switch.
2. For a wireless one, unplug the USB receiver and plug it into a different port. For a Bluetooth one, remove the device in Bluetooth settings and pair it again.
3. Try it on another port, or another computer, to find out whether the device or the laptop is at fault.
4. Restart the laptop.

## The laptop's own keyboard or trackpad

1. Restart the laptop.
2. If a few keys are stuck or missing, turn the laptop off, tilt it and gently blow away crumbs or dust. Do not pull keys off.
3. If the trackpad stopped, check for a function key that turns it off, usually shown with a trackpad symbol.
4. Connect a spare mouse or keyboard so you can carry on working.

## When to raise a ticket

If it still fails, raise a ticket saying which device and what you tried. Keys that are physically broken or a spilled drink need a technician: switch the laptop off and do not turn it back on.
