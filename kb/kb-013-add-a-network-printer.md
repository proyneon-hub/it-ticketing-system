# Add a network printer

Use this the first time you print to a printer, or after removing it.

## Windows

1. Connect to the office network or the VPN.
2. Open Settings, then Printers and scanners, then **Add device**.
3. Choose the printer from the list. Its name is on a label on the front of the printer.
4. Wait for the driver to install, then choose **Print a test page**.

## macOS

1. Connect to the office network or the VPN.
2. Open System Settings, then Printers and scanners, then **Add Printer**.
3. Choose the printer from the list and add it.
4. Print a test page.

## If the printer is not in the list

Check you are on the office network. If you are, raise a ticket with the printer's name and location. The service desk can send you the printer's address to add manually. If the printer was working and now shows offline, see KB-011.
